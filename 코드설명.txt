지하철 하차 알림 좌석 시뮬레이터 - app.py 코드 설명
=====================================================

1. 프로그램의 역할
------------------
app.py는 이 프로젝트의 Python Flask 서버 파일이다.
브라우저 화면을 전달하는 역할뿐 아니라, 좌석 상태·열차 위치·남은 정거장·전광판 문구를 Python에서 계산하고 관리한다.
JavaScript는 Python 서버가 보내 준 결과를 화면에 표시하고, 버튼 클릭 내용을 서버로 전달한다.

2. 사용한 Python 모듈
----------------------
- os
  운영체제 환경변수 PORT를 읽는다. 로컬에서는 5000번 포트를 사용하고, Render 같은 배포 환경에서는 제공된 포트를 사용할 수 있다.

- threading.Lock
  여러 브라우저 요청이 동시에 들어와도 상태값이 꼬이지 않도록 보호하는 잠금 도구이다.
  state_lock을 사용해 한 번에 하나의 요청만 좌석과 열차 상태를 변경하도록 했다.

- time.monotonic
  시스템 시간이 변경되어도 안정적으로 흐르는 시간을 측정한다.
  이 값으로 6초마다 열차를 다음 역으로 이동시킨다.

- Flask, jsonify, render_template, request
  Flask는 Python 웹 프레임워크이다.
  jsonify는 Python 딕셔너리를 JSON 응답으로 바꾼다.
  render_template는 index.html 화면을 브라우저에 전달한다.
  request는 브라우저가 보낸 버튼 클릭 데이터를 읽는다.

3. Flask 앱 생성
-----------------
app = Flask(__name__)

Flask 웹 애플리케이션 객체를 만든다.
__name__은 현재 Python 파일의 이름을 알려 주는 내장 변수이다.

4. 상수와 상태 데이터
----------------------
STATIONS에는 가상 7호선 스타일의 역 이름 목록이 들어 있다.
TRAVEL_SECONDS = 6은 6초마다 한 정거장 이동한다는 의미이다.

state 딕셔너리는 프로그램의 핵심 데이터를 보관한다.

- seat
  id: 선택한 좌석 번호
  occupied: 승객 탑승 여부
  remaining: 남은 정거장 수

- train
  station: 현재 역의 목록 번호
  direction: 진행 방향(1은 정방향, -1은 역방향)
  exited: 하차 완료한 승객 수
  running: 자동 운행 여부
  last_tick: 마지막 이동 시간

5. 주요 Python 함수
--------------------

(1) status_for(seat)
남은 정거장 수에 따라 상태 배지와 CSS 클래스를 결정한다.

- 빈 좌석: 일반 상태
- 0개: 하차 알림
- 1~2개: 하차 임박
- 3~5개: 준비 상태
- 6개 이상: 일반 상태

(2) move_one_station()
열차를 한 정거장 이동시키는 함수이다.
승객이 탑승 중이고 남은 정거장이 1개 이상이면 remaining 값을 1 감소시킨다.
노선의 끝 역에 도착하면 direction을 -1 또는 1로 바꿔 반대 방향으로 회차한다.

(3) advance_elapsed_time()
monotonic 시간 차이를 계산해 6초가 지날 때마다 move_one_station()을 호출한다.
따라서 자동 운행의 핵심 계산은 JavaScript가 아니라 Python 서버에서 처리된다.

(4) display_message()
좌석 상태와 현재 역을 바탕으로 개인 알림판 문구를 Python에서 만든다.

- 승객 없음: 하차 예정 정보를 설정해주세요.
- 0개 역: 이번 역 하차 알림
- 1개 역: 다음 역 하차 예정
- 2개 이상: 하차까지 몇 개 역 남았는지 표시

(5) snapshot()
현재 Python 상태를 JSON으로 안전하게 정리하는 함수이다.
좌석, 열차, 역 목록, 상태 배지, 전광판 문구를 한 번에 브라우저로 보낸다.

6. Flask 주소(API) 기능
------------------------

@app.get("/")
웹사이트 첫 화면 주소이다.
사용자가 사이트에 접속하면 index.html을 보여 준다.

@app.get("/api/state")
현재 시뮬레이션 상태를 JSON 형식으로 반환한다.
요청을 받을 때마다 시간 경과를 계산해 자동 운행 상태도 최신으로 갱신한다.

@app.post("/api/action")
브라우저의 버튼 클릭을 처리하는 API이다.

- action = seat: 탑승, 자리 비우기, +1, -1, reset 처리
- action = set-seat: 좌석 번호 변경
- action = toggle-running: 운행 일시정지 또는 다시 시작
- action = restart: 처음 상태로 전체 초기화

잘못된 요청은 400 오류와 함께 처리해 예외 상황도 관리한다.

7. 서버 실행 부분
------------------
if __name__ == "__main__":
    app.run(...)

이 파일을 직접 실행했을 때 Flask 서버를 시작한다.
host="0.0.0.0" 설정으로 같은 네트워크의 다른 기기에서도 접속할 수 있게 할 수 있고,
PORT 환경변수가 없으면 기본적으로 5000번 포트를 사용한다.

8. 발표용 한 문장 정리
-----------------------

JavaScript는 그 결과를 화면에 시각화하도록 구현했습니다."
