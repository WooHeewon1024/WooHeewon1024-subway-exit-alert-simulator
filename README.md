# 지하철 하차 알림 좌석 시뮬레이터

Flask와 HTML/CSS/JavaScript로 만든 발표용 가상 지하철 객실 시뮬레이터입니다. 실제 지하철 설비, GPS, 운행 데이터와 연결되지 않으며, 좌석별 하차 알림 아이디어의 작동 방식을 시각적으로 보여 줍니다.

## 주요 기능

- 동의한 승객 1석의 탑승, 자리 비우기, 하차 완료 및 남은 정거장 설정
- 7호선 스타일 노선도, 실제 시간의 10배속 자동 운행, 종점 회차와 일시정지
- 남은 정거장별 상태 배지와 이번 역 하차 알림(깜빡임·펄스·선택적 알림음)
- 실시간 전광판, 탑승객/하차 예정/평균 등 통계
- 3초 기본 자동 운행(1~10초 조절)과 발표용 샘플 시나리오

## Python Flask 역할

현재 버전에서는 Python Flask가 단순히 HTML을 전달하는 것을 넘어 시뮬레이션의 핵심 상태를 관리합니다.

- `GET /api/state`: Python이 현재 좌석, 열차, 노선, 전광판 문구, 상태 배지를 JSON으로 계산해 반환합니다.
- `POST /api/action`: 탑승·하차 완료·정거장 수 변경·좌석 번호 변경·운행 정지·초기화를 Python이 처리합니다.
- 자동 운행: Python의 `monotonic()` 시간 계산으로 6초마다 다음 역 이동, 잔여 정거장 감소, 종점 회차를 처리합니다.
- 전광판: Python 함수가 남은 정거장에 맞는 하차 안내 문구와 상태 배지를 결정합니다.

브라우저 JavaScript는 Flask API를 주기적으로 호출해 받은 상태를 화면에 표시하고, 버튼 클릭을 API 요청으로 전달합니다.

## 설치 및 실행 (Windows PowerShell)

가상환경을 만든 뒤 아래 명령을 실행합니다.

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

[브라우저에서 `http://127.0.0.1:5000`으로 접속합니다.](https://wooheewon1024.github.io/WooHeewon1024-subway-exit-alert-simulator/)

## 발표 시연 순서

1. `출근 시간` 또는 `동시 하차` 시나리오를 적용합니다.
2. 전광판의 좌석별 하차 예정 정보와 통계를 확인합니다.
3. `다음 역으로 이동`을 눌러 숫자 감소와 노선도 이동을 보여 줍니다.
4. 남은 정거장이 0인 좌석의 하차 알림을 확인합니다.
5. 해당 좌석의 `하차 완료`를 눌러 누적 하차 승객 수 변화를 보여 줍니다.
6. 자동 운행과 간격 슬라이더, `처음부터 다시 운행`을 시연합니다.

## 한계와 확장 아이디어

이 프로젝트는 실제 차량·GPS·역 정보·통신 장치와 연동하지 않는 브라우저 기반 가상 시뮬레이션입니다. 실제화하려면 운행 API 또는 차량 위치 신호 연동, 좌석 장치 통신, 접근성(진동/음성) 기능, 서버 저장소 및 운영자 화면을 추가할 수 있습니다.
